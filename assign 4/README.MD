Task 3 – Security Principle Mapping
Diffie-Hellman: Key Exchange Protocol. It securely establishes a shared secret key between two parties.
RSA: Encryption algorithm. It uses a public key for encryption and a private key for decryption. It also supports digital signatures.
Task 4 – Threat Model
(a) Use a firewall to allow only required ports (like HTTPS 443) and block unnecessary traffic.
(b) Use both Host-based IDS (HIDS) and Network-based IDS (NIDS) to detect suspicious activities.
(c) Use HTTPS instead of HTTP because it encrypts communication and protects against man-in-the-middle attacks.
(d) Use Two-Factor Authentication (Password + OTP) and follow the principle of least privilege:
Student – View/Submit assignments
Instructor – Manage courses and grade students
Admin – Manage users and system settings
(e) SQL Injection is an Active Attack because the attacker modifies database queries to access or change data.
